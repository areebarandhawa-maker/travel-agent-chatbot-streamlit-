# travel-agent-chatbot-streamlit-
AI-powered travel assistant using Python, Streamlit and Groq API.
✈️ Travel Agent Chatbot

An AI-powered travel assistant built using Python, Streamlit, and the Groq API. The chatbot helps users explore travel destinations, plan itineraries, estimate budgets, and get practical travel advice.

Features
Interactive chat interface using Streamlit
AI-generated travel recommendations
Destination and sightseeing suggestions
Trip planning and itinerary assistance
Travel tips, packing advice, and transportation guidance
Chat history during the current session
Clear Chat button
Environment-based API key management
Technologies Used
Python
Streamlit
Groq API
python-dotenv
Installation
Clone this repository:
bash
git clone https://github.com/YOUR-USERNAME/travel-agent-chatbot.git

Navigate to the project directory:
bash
cd travel-agent-chatbot

Create and activate a virtual environment if desired.
Install the required packages:
bash
pip install -r requirements.txt

Create a .env file and add your Groq API key:
text
GROQ_API_KEY=your_actual_api_key

Start the application:
bash
streamlit run app.py
